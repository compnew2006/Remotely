# Desktop Native Interop

## Overview

This project groups the Linux and Windows native API bindings consumed by the agent and desktop clients.

## Subdirectories & Boundaries

- Linux: [Linux native bindings](./Linux/EGM.md) declare libc, X11, XRandR, and XTest APIs.
- Windows: [Windows native bindings](./Windows/EGM.md) declare Win32 session, process, graphics, desktop, and input APIs.
