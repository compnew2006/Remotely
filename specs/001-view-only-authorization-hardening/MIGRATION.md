# MIGRATION — SPEC-001: تغيير سلوك وضع الوصول الافتراضي

**سريان التغيير:** مع الإصدار الذي يتضمن commit `94d118c5` (SPEC-001).
**المرجع:** FR-025 · FR-026 · FR-027 · SC-008.

## ما الذي تغيّر

| المسار | السلوك القديم | السلوك الجديد |
|---|---|---|
| API: `GET /api/remotecontrol/{deviceID}` (بدون `accessMode`) | جلسة **قابلة للتحكم** بالكامل (الافتراضي `ViewOnly=false`) | جلسة **ViewOnly** |
| API: `GET /api/remotecontrol/{deviceID}?accessMode=FullControl` | — (غير موجود) | FullControl **فقط** لمتصل مُصادَق عليه لديه device-group access؛ وإلا ViewOnly مع تسجيل الرفض |
| واجهة المستخدم: زر "Remote Control" في بطاقة الجهاز | جلسة قابلة للتحكم | **لم يتغير** — طلب صريح مُصادَق من مدير (مسار FR-005) |
| واجهة المستخدم: زر "View Only" | جلسة عرض فقط | **لم يتغير** |
| رابط عارض (`/Viewer?...&viewonly=...`) | الباراميتر يقرر فعليًا | **ميت أمنيًا** — العارض لا يستطيع رفع صلاحيته؛ الوضع يُقرأ من حالة الجلسة على السيرفر (FR-002/FR-006) |
| تبديل جلسة Windows / استنساخ الجلسة | يمسح وضع العرض (يتحكم دائمًا) | **يحفظ** وضع الجلسة؛ لا ترقية أبدًا (FR-013) |
| الجلسات Attended (رقم من 9 خانات) | تحكم مباشر بعد موافقة المستخدم على الجهاز | **لم يتغير** — الموافقة على الجهاز هي أساس الصلاحية (آلية الموافقة القائمة، إعادة استخدام موثقة) |

## صيغة الطلب المتأثرة

- `GET /api/remotecontrol/{deviceID}` — إضافة باراميتر اختياري `accessMode` (`ViewOnly` \| `FullControl`، غير حساس للحالة).
- **الاستجابة:** نص الرابط كما هو (غير مكسور)، مع ترويسة جديدة قابلة للقراءة آليًا: `X-Remote-Control-Access-Mode: ViewOnly|FullControl` (FR-022/FR-027).

## خطوات الإصلاح للمُدمجين (Integrators)

1. احتاجتَ التحكم؟ اطلبه **صريحًا**: `?accessMode=FullControl`، بهوية مُصادَقة (مستخدم + API key) يملك صلاحية الجهاز.
2. اقرأ `X-Remote-Control-Access-Mode` من الاستجابة لتحديد الوضع المُطبَّق فعليًا — لا تفترض.
3. طلب FullControl بهوية غير مُصادَقة يُرفض ويُسجَّل؛ النتيجة ViewOnly (fail-closed، FR-009).

## ما لا يمنحه أحد

- امتلاك `accessKey` أو رابط عارض أو تعديل URL **لا يمنح** FullControl إطلاقًا (FR-006).
- تعديل الصفحة/الرابط في المتصفح لا يغيّر وضع الجلسة في 0% من الحالات (SC-006) — الفرض يقع على السيرفر والجهاز معًا.
