## 2. ما تثبته الأدلة

- الملفات **مُولَّدة**، وليست مكتوبة يدويًا: `graphify-out/2026-11-08/manifest.json` يسرد كل `EGM.md` مع `mtime` و`seen` و`ast_hash`.
- كل ملف يتبع قالبًا ثابتًا: `Overview` · `Interface` · `Invariants` · `Side Effects` · `Verification`.
- لا يوجد في CI أو الشيفرة أي مرجع إلى `EGM.md`؛ المرجع الوحيد هو فهرس الجذر والـmanifest.
- الملفات **لا تحمل حالة بوابة** ولا `PASS/FAIL`؛ لذلك ليست مصدر حالة، ولا تنافس `GATE-REGISTER.md`.

## 3. المخاطر

1. أي توليد جديد بـ`graphify` يعيد كتابة الملفات بجانب الشيفرة، فأي نقل يدوي سيُلغى.
2. نقل 96 ملفًا دون تحديث روابط الفهرس ينتج روابط مكسورة.
3. حذف الملفات من الـworking tree يفقد محتوى لم يُراجَع بعد، ولا رجوع له إلا من git.

## 4. الخيارات

### الخيار أ — إلغاء التتبع مع الإبقاء على الملفات (موصى به)

الأقل تدميرًا: تُبقي الملفات على القرص للاستخدام المحلي، وتخرج من المستودع، ويُضاف نمط تجاهل.

```powershell
git rm --cached (git ls-files '*EGM.md')
Add-Content .gitignore "`n# Generated structural maps (graphify)`nEGM.md`n**/EGM.md"
```

- المجموع بعدها: 0 ملف `EGM.md` متتبع.
- تُحدَّث تعليمات التوليد في `AGENTS.md` لتصبح: الملفات مخرجات محلية غير متتبعة.
- يبقى `docs/egm/` غير مستخدم.

### الخيار ب — أرشفة الشجرة كاملة

نقل الشجرة مع الحفاظ على البنية النسبية، وتحديث فهرس الجذر.

```powershell
git ls-files '*EGM.md' | ForEach-Object {
    $target = Join-Path 'docs/egm' $_
    New-Item -ItemType Directory -Force (Split-Path $target) | Out-Null
    git mv $_ $target
}
```

- يبقى مؤشر صغير في `EGM.md` بالجذر يحوّل إلى `docs/egm/EGM.md`.
- يُعاد توليد الملفات لاحقًا في مواقعها القديمة ما لم يُضبط مسار أداة التوليد.
- يحتاج موافقة المالك لأنه يغيّر مواقع 96 ملفًا.

### الخيار ج — الإبقاء كما هي مع توثيق السلطة

لا نقل ولا حذف. تُوسم الملفات كخرائط بنيوية فقط، ويُعلن `GATE-REGISTER.md` مصدرًا وحيدًا للحالة.

- الأنسب إن كان المالك يريد الاحتفاظ بالملفات في المستودع للمراجعة.

## 5. التوصية

الخيار **أ**، ثم **ج** كحد أدنى. السبب:

- الملفات مخرجات توليد، وإبقاؤها متتبعة يجعل كل تحديث شيفرة يضيف ضجيجًا في الـdiff.
- لا خسارة معرفية: المحتوى قابل لإعادة التوليد من الشيفرة نفسها.
